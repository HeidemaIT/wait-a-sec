# Wait a Second

Minimal Android app that reuses the calm Material 3 design from Ninety Seconds.

## Run

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

Open the project in Android Studio, or install with:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
